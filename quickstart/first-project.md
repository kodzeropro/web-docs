# Первый проект

В Kodzero вы можете создать несколько проектов в одном аккаунте. Каждый проект — это изолированное пространство со своими коллекциями, пользователями и файлами.

::: tip :bulb: Рекомендация
Используйте **один проект на одно приложение**. Это упрощает управление данными и разграничение доступа.
:::

::: info <IconBeta /> beta-режим
Сейчас платформа работает в beta-режиме — подписка не требуется. В будущем тарификация будет расчитываться отдельно для каждого проекта.
:::

## Создание проекта

1. Войдите в [панель управления](https://kodzero.pro/auth)
2. Нажмите **«Создать проект»**
3. Введите название проекта и нажмите **«Создать»**

## Создание первой коллекции

Давайте создадим коллекцию `products` для хранения товаров.

### Шаг 1. Добавьте коллекцию

1. В меню выберите **«Коллекции»**
2. Нажмите **«Новая коллекция»**
3. Введите название: `products`

### Шаг 2. Настройте схему

Добавьте поля для коллекции:

| Поле | Тип | Описание |
|------|-----|----------|
| `title` | Текст | Название товара |
| `price` | Число | Цена товара |

Нажмите **«Сохранить»** для применения схемы.

### Шаг 3. Настройте доступ к API

1. Перейдите в **«Настройки API»** коллекции
2. Установите доступность: **Public**
3. Отключите методы: `Create`, `Update`, `Delete`
4. Оставьте включёнными: `View All`, `View`
5. Нажмите **«Сохранить»**

::: warning Важно
Публичный доступ с отключёнными методами записи позволяет читать данные без авторизации, но защищает от изменений.
:::

## Создание первой записи

Добавим тестовую запись в коллекцию:

1. Откройте коллекцию `products`
2. Нажмите **«Добавить запись»**
3. Заполните поля:
   - `title`: Футболка
   - `price`: 1499.99
4. Нажмите **«Сохранить»**

Запись появится в таблице данных коллекции.

## Проверка API

1. Скопируйте **«Путь API»** из настроек коллекции
2. Откройте ссылку в браузере
