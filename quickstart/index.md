# Что такое Kodzero

**Kodzero** — это облачная Backend-as-a-Service платформа, которая позволяет создавать бэкенд для приложений и веб-сайтов без написания серверного кода.

## Возможности

С Kodzero вы получаете:

- 🗄️ **База данных** — создавайте коллекции и управляйте данными через веб-интерфейс
- 📡 **REST API** — автоматически генерируемый API для работы с данными
- 🔐 **Аутентификация** — готовая система регистрации и авторизации пользователей
- 📁 **Файловое хранилище** — загрузка и хранение файлов в облаке (S3)
- 🔌 **SDK** — JavaScript/TypeScript-пакет для быстрой интеграции
- ⚡ **Realtime** — подписки на изменения данных через WebSocket (soon)

## Для кого подходит

- **Разработчикам** — сосредоточьтесь на UI, а не на бэкенде
- **Стартапам** — быстро запускайте MVP без лишних затрат
- **Предпринимателям** — используйте готовую инфраструктуру для расширения вашего бизнеса
