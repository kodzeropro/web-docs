# Что такое коллекции

Коллекция — это структурированное хранилище данных в Kodzero. По сути, это таблица в базе данных с автоматически сгенерированным REST API.

## Основные компоненты

Каждая коллекция состоит из:

| Компонент | Описание |
|-----------|----------|
| [**Данные**](./data) | Записи (строки) в таблице |
| [**Схема**](./schema) | Структура полей и их типы |
| [**Настройки API**](./api-settings) | REST-эндпоинты, права доступа и конфигурация методов |

## Создание коллекции

1. Перейдите в раздел **«Коллекции»** в панели управления
2. Нажмите **«Новая коллекция»**
3. Введите название коллекции
4. Выберите тип коллекции
5. Подтвердите

::: tip :pushpin: Рекомендация по названию
Используйте понятные названия в нижнем регистре: `products`, `users`, `orders`. Это упростит работу с API.
:::

## Типы коллекций

При создании коллекции выберите её тип в зависимости от задачи.

| Тип | Особенности |
|-----|---------------------|
| **Данные** | Универсальная коллекция для хранения бизнес-сущностей приложения: товары, статьи, заказы, задачи |
| **Пользователи** | Для регистрации, входа и хранения профилей пользователей |

### Тип «Данные»

Подходит для большинства сценариев: каталоги, контент, рабочие объекты, события и другие сущности вашего проекта.

### Тип «Пользователи»

Нужна, если в проекте есть учётные записи и авторизация. В этой коллекции хранятся пользовательские данные и настройки стратегий входа.

Подробнее о работе с коллекцией типа «Пользователи»: [Авторизация в SDK](../sdk/auth).
