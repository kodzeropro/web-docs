# Когда использовать

Используйте серверную интеграцию, если вам нужно:

- создавать заказы с дополнительными проверками;
- выполнять сложные вычисления;
- работать с платежными системами;
- объединять данные из нескольких источников;
- выполнять фоновые задачи;
- запускать CRON-задачи;
- обрабатывать вебхуки;
- реализовывать собственные API-эндпоинты.

## Практический ориентир

Если задача решается стандартным клиентским CRUD-потоком, чаще всего достаточно обычного API-доступа.

Если вам нужен дополнительный слой бизнес-логики между frontend и данными, выбирайте серверную интеграцию.

## Примеры задач

Ниже приведены наиболее распространенные сценарии, в которых серверная интеграция становится особенно полезной.

### Бизнес-логика

Реализуйте собственные серверные сценарии, которые невозможно или небезопасно выполнять на стороне клиента.

Например:

- проверка наличия товаров перед созданием заказа;
- расчет скидок, комиссий и стоимости доставки;
- создание нескольких связанных записей в рамках одной операции;
- выполнение дополнительной валидации данных.

---

### Интеграции с внешними сервисами

Используйте Kodzero как источник данных для взаимодействия с другими системами.

Например:

- создание платежей в платежной системе;
- синхронизация данных с CRM;
- отправка уведомлений в Telegram или по электронной почте;
- обмен данными с любыми внешними API.

---

### Фоновые задачи

Выполняйте серверные процессы без участия пользователя.

Например:

- запуск CRON-задач по расписанию;
- пересчет статистики;
- очистка устаревших данных;
- импорт данных из внешних источников;
- генерация документов и файлов.

---

### Отчеты и аналитика

Собирайте данные из нескольких коллекций, выполняйте необходимые вычисления и формируйте готовые результаты.

Например:

- ежедневные отчеты по продажам;
- финансовую аналитику;
- статистику использования сервиса;
- пользовательские дашборды и агрегированные показатели.
