# Ошибки

При использовании Admin API-ключа Kodzero использует стандартные HTTP-коды ответов.

## Ошибки аутентификации

### Отсутствует `X-Kodzero-Profile: admin`

Если заголовок `X-Kodzero-Profile: admin` не передан, запрос **не** завершается ошибкой `401` или `403`.

В этом случае запрос обрабатывается как обычный запрос к стандартному REST API по тому же адресу.

Это означает, что дальше применяется стандартная логика доступа коллекции и метода (Public/User/Workspace).

### 401 Unauthorized

Возвращается, если запрос не удалось аутентифицировать.

Возможные причины:

- Admin API-ключ не передан;
- ключ указан неверно;
- ключ был удален или больше не действителен;

Проверьте наличие обязательных заголовков:

```http
Authorization: Bearer KODZERO_ADMIN_API_KEY_READ
X-Kodzero-Profile: admin
```

## Ошибки доступа

### 403 Forbidden

Возвращается, если запрос успешно аутентифицирован, но у ключа недостаточно прав для выполнения операции.

Например:

- использование ключа **Только чтение** для создания, изменения или удаления данных;
- выполнение операции, которая не разрешена текущим уровнем доступа.

В этом случае необходимо использовать ключ с подходящими правами или изменить логику приложения.

## Другие ошибки

Остальные ошибки работают так же, как и при обычном использовании REST API Kodzero.

Например:

- `404 Not Found` - запрашиваемый ресурс не существует;
- `400 Bad Request` - некорректные параметры запроса или данные;
- `500 Internal Server Error` - внутренняя ошибка сервера.

Полный список ошибок REST API описан в разделе [Ошибки](/api/errors).
