# Серверная интеграция

Серверная интеграция позволяет вашему серверу выполнять запросы к REST API Kodzero с административными правами при помощи **Admin API-ключа**.

Это даёт возможность строить собственную бизнес-логику поверх Kodzero, сохраняя преимущества стандартного REST API.

## Два сценария использования

### Простой сценарий

```text
Frontend
    ↓
Kodzero REST API
```

### Расширенный сценарий

```text
Frontend
    ↓
Ваш сервер
    ↓
Admin API-ключ
    ↓
Kodzero REST API
```

В расширенном сценарии ваш сервер выполняет роль слоя бизнес-логики: проверяет условия, делает дополнительные вычисления и только затем отправляет запросы в Kodzero.

## Адрес для запросов

Для запросов с админ-профилем используется **тот же адрес коллекции**, что и в обычном (неадминском) сценарии. Переключение в административный маршрут происходит за счет заголовка `X-Kodzero-Profile: admin`.
